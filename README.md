# 🎧 Vibify — A Spotify-Like Music Player (Vanilla JS)

Vibify is a lightweight, Spotify-inspired music player built using **HTML, CSS, and vanilla JavaScript**.  
It dynamically loads music folders, displays playlists, and provides a full playback experience — all without any frameworks.

This project was built to deeply understand **DOM manipulation, async JavaScript, event handling, and audio APIs**.

---

## 🚀 Features

- 🎵 Dynamic playlist loading from folders
- ▶️ Play / Pause / Next / Previous controls
- 📂 Folder-based music organization
- 📃 Song library with clickable tracks
- ⏱ Live duration & progress bar
- 🎚 Volume control with mute toggle
- 📱 Responsive sidebar (hamburger menu)
- 🎶 Animated playing indicator (GIF)
- 🔄 Auto-play next song
- 🎨 Spotify-style UI

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3** (Utility classes + custom styling)
- **JavaScript (ES6+)**
- **HTML Audio API**

No frameworks. No libraries. Just pure web fundamentals.
